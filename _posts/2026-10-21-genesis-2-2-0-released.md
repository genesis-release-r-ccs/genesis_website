This version has the following updates.

-   Added adaptively biased molecular dynamics (ABMD) and its variants.
-   Added a new MD engine for coarse-grained simulations: CGDYN.
-   Added Mpipi for coarse-grained intrinsically disordered proteins and RNA.
-   Added iSoLFv2 for coarse-grained lipid simulations.
-   Added SPICA/pSPICA for explicit-water coarse-grained simulations.
-   Added a new Langevin integrator based on the BAOAB scheme.
-   Added support for LLVM/Clang and NVIDIA compilers.
-   Added support for AMD GPUs.

Check the [full release note](/releases/genesis_version_2.2/).
